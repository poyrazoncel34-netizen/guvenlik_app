# google-services.json

Bu dosya Firebase Console'dan indirilmelidir. Repo'ya commit edilmez (.gitignore).

## İndirme Adımları

1. [Firebase Console](https://console.firebase.google.com) → Projenizi seçin
2. Project Settings (dişli) → Your apps
3. Android app `com.poyrazoncel.korubeni` → **Download google-services.json**
4. İndirilen dosyayı `android/app/` içine kopyalayın

## Konum

```
android/app/google-services.json
```
