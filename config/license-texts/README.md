# Reviewed licence bytes

Place each human-reviewed primary-source licence text in this directory as
`<sha256>.txt`. The filename is the SHA-256 of the exact UTF-8 bytes and must
match the corresponding `sha256` in `dependency_license_evidence.json`.

Do not add generated registry summaries or guessed licence text. Reviewer,
date, SPDX decision and primary-source URL remain accountable evidence fields.
