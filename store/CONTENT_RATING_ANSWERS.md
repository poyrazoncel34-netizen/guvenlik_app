# Play Console — Content Rating Questionnaire Yanıtları

Content rating anketinde (IARC) aşağıdaki gibi yanıtlayın. KoruBeni bir güvenlik uygulamasıdır.

---

## Önerilen Yanıtlar

### Şiddet (Violence)
- **Cartoon or fantasy violence:** None
- **Realistic violence:** None
- **Prolonged graphic or sadistic violence:** None

### Cinsellik (Sexual content)
- **Nudity or sexual content:** None
- **Sexual themes:** None

### Dil (Language)
- **Profanity or crude humor:** None
- **Mature/suggestive themes:** None

### Kontrollü Maddeler (Controlled substances)
- **Alcohol, tobacco, drugs:** None

### Korku / Korkutucu İçerik (Fear / Horror)
- **Horror themes:** None
- **Fear themes:** None (güvenlik uygulaması, korku amaçlı değil)

### Tehlikeli Davranışlar (Dangerous activities)
- **Simulated gambling:** None
- **Unrestricted web access:** No (uygulama harici tarayıcı açmıyor)
- **User-generated content:** No
- **Shares location:** No automatic sharing — location is processed for emergency/location session when user triggers it

### Diğer
- **Social interaction:** Yes — emergency contacts / call flow
- **Personal information shared:** No automatic app-to-contact sharing. Emergency calls may expose the caller's phone number through the phone network; location is processed for the emergency/map session when user triggers it.

---

## Beklenen Sonuç

Genelde **PEGI 3** / **Everyone** veya **Everyone 10+** benzeri çıkar. Anketi bitirdikten sonra sertifikayı alın ve Play Console’a kaydedin.
