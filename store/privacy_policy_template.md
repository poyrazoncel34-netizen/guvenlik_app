# Privacy Policy

**Full HTML versions are available at:**
- Turkish: `store/privacy_policy.html`
- English: `store/privacy_policy_en.html`

**Hosting:** Upload one of these HTML files to your web hosting or GitHub Pages and use the URL in:
- Google Play Console → Store Listing → Privacy Policy URL
- App Store Connect → App Information → Privacy Policy URL
