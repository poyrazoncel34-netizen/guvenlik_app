# Store Screenshots

Bu klasöre aşağıdaki ekran görüntülerini ekleyin:

## Play Store (Android)
- **Min 2, max 8** screenshot gerekli
- Önerilen boyutlar: 1080x1920 veya 1080x2340
- Format: PNG veya JPEG

Önerilen ekranlar:
1. Ana sayfa (panik butonu)
2. Acil kişiler listesi
3. Harita / konum paylaşımı
4. Güvenli yürüyüş
5. Ayarlar

## App Store (iOS)
- **6.7"** (iPhone 15 Pro Max): 1290x2796
- **6.5"** (iPhone 14 Plus): 1284x2778
- **5.5"** (iPhone 8 Plus): 1242x2208

Aynı ekranlar farklı boyutlarda çekilebilir.

## Nasıl alınır
1. Uygulamayı gerçek cihazda veya emülatörde çalıştırın
2. Android: `adb shell screencap` veya ekran görüntüsü
3. iOS: Simulator'da Cmd+S veya cihazda yan tuş + güç
4. Dosyaları bu klasöre kopyalayın: `screenshot_1.png`, `screenshot_2.png` vb.
